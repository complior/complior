## 3. Architecture Requirements (mandatory for nodejs-dev)

### Date helpers (HR-T4)
Create new module `engine/core/src/domain/reporter/format-dates.ts`:

```ts
/** Format ISO date as "April 28, 2026" — locale-independent, deterministic. */
export const formatDateHuman = (iso: string): string => { ... };

/** Format ISO datetime as "April 28, 2026 at 10:48 UTC" — locale-independent. */
export const formatDateTimeHuman = (iso: string): string => { ... };
```

- Pure functions — no side effects
- `Object.freeze` not applicable (returns string)
- Use `Intl.DateTimeFormat('en-US', { ... })` with explicit options
- Returns the input unchanged if `iso` is invalid (no throw)
- Both helpers exported as named exports
- Co-located test file `format-dates.test.ts` with these specs:
  - `formatDateHuman('2026-04-28T10:48:32.816Z')` === `'April 28, 2026'`
  - `formatDateHuman('2026-08-02')` === `'August 2, 2026'`
  - `formatDateHuman('not-a-date')` === `'not-a-date'` (invalid → unchanged)
  - `formatDateTimeHuman('2026-04-28T10:48:32.816Z')` === `'April 28, 2026 at 10:48 UTC'`
  - `formatDateTimeHuman('not-a-date')` === `'not-a-date'`
